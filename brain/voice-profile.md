## The do-not-write list

Global bans, on top of the AI-speak list in `/CLAUDE.md`. Add to this every time
something makes you wince.

| Never write | Because | Write instead |
|---|---|---|
| em dashes | reads slow on a phone, breaks dubbing | period, comma, or colon |
| "she felt <emotion>" | inert on screen, an actor cannot play it | the physical tell |
| "shatters the silence" | AI-speak | the sound itself |
| | | |

## Working preferences

- Give me the work first, notes after.
- When I ask for options, give 2 to 4 ranked, recommendation first, with what each one
  trades off. Not one path.
- Tell me when something is bad. Name the line, say why, hand me the replacement.
- Do not ask permission for things you can just do and show me.
