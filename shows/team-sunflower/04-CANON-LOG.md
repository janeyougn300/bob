# CANON LOG: TEAM SUNFLOWER

Append-only. Every decision a future session would otherwise re-litigate or contradict.

**This file is the credit saver.** Without it, every new session re-derives what you
already decided, and sometimes decides differently. Ten seconds of writing here saves
a full re-explaining session later.

Write to this file at the end of every working session. Newest at the top.

---

## Format of an entry

```
### YYYY-MM-DD. <what this was about>
DECIDED: the thing that is now true.
BECAUSE: the reason, so a future session does not undo it.
AFFECTS: which episodes, characters or files.
```
